# Sendo

A Telegram-based stablecoin bill-pay and remittance agent for Nigerian users, built on Celo.

## What it does

Sendo lets users pay bills and send money across borders through a Telegram bot,
settling in cNGN on Celo. No exchange app, no seed phrase to manage manually —
just a chat interface for moving stablecoins where they're needed.

Gas is paid via fee abstraction, so users transact in cNGN without needing to
hold CELO first — the barrier that keeps most non-crypto-native users out.

## Built for

**Celo Agents at Work Hackathon** (Aug 28 – Sep 14, 2026)

Targeting:
- **Track 1 — Value Moved**: real remittance/bill-pay transactions between independent users
- **Track 2 — Real World Adoption (Best Stablecoin Adoption)**: cNGN-settled transactions, distributed via Telegram
- **Track 4 — Judges' Favorite**: fee abstraction as the core unlock for non-crypto-native users
